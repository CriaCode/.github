# CriaCode Agência

Desenvolvemos sistemas web, sites profissionais e soluções digitais para empresas que querem melhorar sua presença online, automatizar processos e organizar melhor seus serviços.

## Sobre a CriaCode

A CriaCode Agência é uma empresa de desenvolvimento focada em criar soluções digitais sob medida para negócios.

Atuamos no desenvolvimento de sistemas web, sites institucionais, landing pages, plataformas administrativas e produtos digitais próprios.

Nosso objetivo é transformar ideias em soluções simples, funcionais e escaláveis.

## O que fazemos

- Desenvolvimento de sistemas web sob medida
- Criação de sites profissionais
- Landing pages para captação de clientes
- Painéis administrativos e dashboards
- Integrações com APIs e serviços externos
- Soluções digitais para automação de processos
- Produtos próprios, como o BarbClub

## Tecnologias

Trabalhamos com tecnologias modernas para entregar soluções seguras, organizadas e de fácil manutenção.

- PHP
- Laravel
- JavaScript
- MySQL / SQL Server
- APIs REST
- Git / GitHub

## Produtos

### BarbClub

O BarbClub é um produto da CriaCode voltado para barbearias que desejam ter presença online, agenda digital e melhor controle do atendimento.

Com ele, a barbearia pode divulgar seus serviços, receber agendamentos online e organizar melhor sua rotina.
